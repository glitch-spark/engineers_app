## Global Constraints

- Statistics tabs, in order: `Team · Bids · Interviews · Callers · Profiles · Resumes · AI usage` (`?tab=` values `team, bids, interviews, callers, profiles, resumes, ai-usage`; old `resume-compare` maps to `resumes`).
- Visibility doesn't change: Statistics and the earnings ranking stay visible to all signed-in users as today; admin-only data stays admin-only (`/dashboard/team`); staff see only their own profiles' metrics (as `GET /accounts/metrics` enforces).
- Work pages keep at most a small summary with a link to the full numbers in Statistics.
- Resume unit's one name: **"Resume variant"** (plural "Resume variants") in all user-visible copy; code identifiers (`resumePrompts`, `ResumeUnitsEditor`) don't need renaming.
- Default prompts live at Profiles → **Default prompts** (route `/accounts/prompts`); `/preferences` redirects there (keeping the query). The Generate tabs become `Generate · Generated resumes`.
- Bidder bids, everywhere: **Bid Track records, approved + pending**, counted per owner on the Bid Track report day. The typed `done.bidsBidder` stays stored but is no longer read for Done; the bidder **goal** stays typed.
- Net income, everywhere: **approved transactions only**. Pending is shown separately, never mixed into net.
- Home (`/dashboard`, sidebar label **Home**) shows what needs doing first, then progress; it has no team ranking (that's Statistics → Team).
- Exact copy:
  - Profiles row link: `Stats →`
  - Profile editor link (replacing the Metrics tab): `View stats in Statistics →`
  - Plans bidder Done hint: `From Bidders (approved + pending)`
  - Transactions footer: `Net (approved)` and `Pending`
  - Home empty state: `Nothing needs you right now.`
